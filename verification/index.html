What this session changed its mind about

Three findings worth the scroll

Each one was found by opening something, not by reasoning about it.

Deploy scope

The site serves its own source code

Pages is set to publish the repository root, not the staged build. Opening /tools/build.py on the live host returns the build script. Opening /archive/notes-edition/ returns a retired storefront with its own title and its own sponsored links. Five editions of one shop are live at five addresses.

Fix: one Pages setting. Logged as OFF-02, rank 2.

Image rule

Half the pictures were photographs on a site that said they were drawings

My first pass found one photoreal image in the seasonal band and called it an outlier. Opening the rest showed the opposite: eight of the seventeen images in use were photographic renders, including the images on product pages P-02 and P-04, where a photograph beside a buy button reads as evidence of the product. The register called them all illustrations, and the disclaimer on each product page contradicted the picture above it.

Fix: all eight replaced with engravings this session; the rule now states one visual language. Logged as OFF-05, and corrected above rather than edited away.

Conversion path

Every click cost the reader a second decision

All 133 tagged links in this repository pointed at a product-detail page. A reader who had already decided still had to land, scroll, and find Amazon's own button. The cart endpoint was opened to confirm it accepts the URL shape, and is now used on the front page.

Shipped: two cart doors now sit on the front page. Because no Special Link is approved, they carry no tag, so the click is a reference link until OFF-01 lands.

Row by row

The detail behind each verdict

Short, specific, and where possible naming the file or the URL to open.

index.html Shortlist cards Holds, with a caveat

5 of 5 listings matched on title and breadcrumb. The route from the submitted short link is the caveat: one reached its recorded listing, two fell through to Amazon's home page and two would not fetch, so a sentence about following the link is not reproducible from outside the account. The front-page wording was narrowed to what two sessions can support, and the row-level evidence sits on the second-read log. Intent stays FLG-001; this is FLG-055.

index.html Disclosure strip Holds

The sentence is verbatim and required. Since the merge with main the site publishes no synthetic tag, so the disclosure and the link state agree: the relationship is declared as an obligation, not claimed as a credited fact. Attribution is unproven until a click appears in an Associates report (FLG-002).

index.html "How this works" band Holds

Consistent with Program Policies 2(b), which permits a price only from an Amazon-served link or the APIs.

index.html Seasonal feature Needs rewording

Corrected during this session. My first pass found one photoreal image here and called it an outlier. Opening the rest showed eight of seventeen in-use images were photographic, including P-02, P-04, the thermometer guide and the cleanup guide — so the register's stated rule ('illustrative editorial photography only') described almost nothing. All eight have been replaced with engravings and the rule now describes the set.

products/p-01.html … p-05.html Feature lists Holds

The quoted capacities (6 qt / two 3 qt, 8 qt, 26 qt) all appear in the listing titles.

products/* Add-to-cart call to action Holds, with a caveat

The endpoint accepts the URL and, for an anonymous visitor, returns a sign-in page first. The permalink carries no AssociateTag, matching the withdrawn-tag state, so the click is a plain reference link and the button does not pretend otherwise.

guides/* Read-time labels Holds, with a caveat

800 words is roughly 3–4 minutes at 200–250 wpm, not 7. The labels are a self-estimate, not a measurement, and they are generous to the site. Recorded as a wording issue, not a factual claim about a product.

compare/index.html Side-by-side table Holds

No cell states a price, a rating or an availability. The table compares form factor only.

fit/index.html Format finder Holds

Important distinction: a recommender that named a product would be making an unverified performance claim. This one does not.

about/index.html Source register Holds, with a caveat

One FTC URL used elsewhere in the repository (consumer.ftc.gov/business-guidance) is a redirect target, not the canonical page. The canonical page opened is the one linked here.

review/index.html Flag register Holds

Self-consistent. Two new findings from this session are added rather than folded into existing flags, so the count on this page and the count on /verification/ differ by design.

questions/index.html Question register Holds, with a caveat

The closed rows rest on policy text, which opened. But the two questions that matter most for revenue (Q-01, Q-03) are both open, so the 'closed' count is not a measure of readiness.

offers/index.html Ranked board Holds

The weights are judgements. They were changed once during this session, after the first run ranked a tidying task above the task that decides whether any money can arrive; the change is recorded in offers.json rather than applied silently.

verification/index.html This page Holds, with a caveat

The audit covers the pages this session could open. It is not a guarantee that no weaker claim elsewhere is wrong; it covers the strongest claim on each of the main surfaces.

sitemap.xml / feed.xml Machine-readable surface Holds

The retired editions under archive/ are absent from the sitemap, which is correct, but 22 of them carry no noindex tag and are live on the host. See the deploy-scope row on /verification/.

robots.txt Crawl directive Needs rewording

Allow: / is accurate about the host and wrong about the intent: it invites a crawler into /tools/, /src/, /archive/ and five retired storefronts, because the host serves the whole repository. The directive is not the bug; the deploy scope is.

What this page is not

It is not a guarantee that every sentence on the site is correct. It covers the strongest claim on each main surface, which is where an error does the most damage. A weaker sentence elsewhere can still be wrong, and finding it needs the same treatment: open the page, read the claim, open the source.
