Registers and dashboard surfaces

The verification and review surfaces, kept reachable from the footer so the buyer-facing front page can stay buyer-facing.

Where this page came from. The front page was rebuilt to lead with the products rather than the audit trail. The audit trail is not gone, it moved here. One correction to the record: this repository had no earlier site to preserve — at the starting commit it held a single eight-byte README. Nothing was deleted. What this page collects is the register set built in this pass, so a reviewer can reach every surface from one place.

Why these are not in the main navigation

A reader deciding between two air fryers does not need a register of policy quotations. A reviewer does. Splitting them keeps one navigation group that reads like a shop, while leaving every register one click from the footer — which also means no dashboard surface is unreachable, only undemoted.
