Decision suggestions

This page is the decision gate. Nothing here is implemented until reviewed. Each suggestion states what it would change, what evidence it needs, and its impact/effort. Pick the best path, then implement — in that order. Updated 2026-11-20.

SUG-01 · shipped · Impact 5/5 · Effort 1/5

Publish the disclosure in a strip under the masthead, and again in the footer

Both Amazon's Operating Agreement and the FTC's guidance put the duty on the publisher, and the FTC's test is whether a reader can weigh the recommendation at the moment they read it. A disclosure only in the footer fails that test on a long page.

Evidence needed: none; the sources are already read and quoted

SUG-02 · shipped · Impact 5/5 · Effort 1/5

Stop publishing prices, star ratings and review counts entirely

Program Policies 2(b) allows price display only when Amazon serves the link carrying the data, or when it comes from the Creators API / PA API. This site has no such feed. A stale price is also a misrepresentation risk under the same section.

Evidence needed: none

SUG-03 · shipped · Impact 5/5 · Effort 1/5

Keep intended ASIN and observed redirect target as two separate, never-merged fields

The observed redirect is a fact about today's redirect. The intended ASIN is a fact about what the owner meant to enrol. Merging them destroys the only audit trail that would catch a wrong-product redirect.

Evidence needed: none

SUG-04 · shipped · Impact 4/5 · Effort 3/5

Build the landing page as a publication front page, with the audit surfaces demoted to the footer

A buyer arriving from a search result needs a reason to stay within about five seconds. A verification table is a reason to leave. The register still has to exist; it just should not be the front door.

Evidence needed: post-launch: scroll depth and outbound click rate by page

SUG-05 · shipped · Impact 4/5 · Effort 3/5

Write question-shaped guides, one per real buyer decision, and link products from inside the argument

A guide that answers a question earns a link and a share; a product card does not. Question-shaped titles also match how people type into a search box.

Evidence needed: Search Console query data after 4–6 weeks

SUG-06 · shipped · Impact 3/5 · Effort 1/5

Ship an RSS feed and one canonical host, before chasing traffic

Syndication gives a second surface for free and makes the publishing cadence visible. Duplicate hosts split whatever authority the site earns.

Evidence needed: none for the mechanics

SUG-07 · blocked-on-decision · Impact 4/5 · Effort 2/5

Define the five events and a privacy-preserving outbound-click counter — but deploy nothing until a host is chosen

Measurement has to exist before optimisation, or the next decision is made on instinct. But an unhosted endpoint and an unconsented cookie are worse than no measurement: one is dead code, the other is a compliance problem.

Evidence needed: a first-party host (see FLG-009)

SUG-08 · blocked-on-account · Impact 5/5 · Effort 1/5

Test exactly one Special Link end to end before scaling to five

If the tag is dropping, one wrong link and five wrong links cost the same in lost trust but five is a bigger hole. One-link-per-product, confirmed in the Associates report, is the cheapest possible experiment.

Evidence needed: an Associates dashboard session

SUG-09 · shipped · Impact 4/5 · Effort 2/5

Add a comparison table that compares on decisions, not on specs we cannot verify

A reader choosing between a dual basket and a French-door oven wants to know which one their counter and their family size can actually accommodate. That comparison is honest without needing a wattage figure we cannot source.

Evidence needed: none for the form-factor comparison; dimensions would need a feed

SUG-10 · shipped · Impact 3/5 · Effort 1/5

Publish a 'Flagged for Review' page and keep it visible in the footer

Every unverified value has to be reviewable by the person who can actually resolve it. A hidden to-do list gets ignored; a public page with source links gets acted on.

Evidence needed: none

SUG-11 · blocked-on-decision · Impact 4/5 · Effort 2/5

Add author identity and a methodology page before adding more content

Readers and search engines both discount anonymous product advice. An author page with a real name, a stated method and a correction policy is the cheapest credibility upgrade available.

Evidence needed: a real name and a real bio from the owner

SUG-12 · proposed · Impact 3/5 · Effort 2/5

Publish one guide every two weeks rather than five at once

A cadence is a signal that the site is maintained. A burst followed by silence reads as abandoned, and it also makes it impossible to attribute a change in traffic to a topic.

Evidence needed: Search Console data to confirm the cadence is producing indexed pages

SUG-13 · blocked-on-decision · Impact 3/5 · Effort 4/5

Add a reader-capture email list

An email list is the only audience asset that survives an algorithm change. It is also the highest-risk item on this list, because it brings CAN-SPAM, consent records and a provider into scope at once.

Evidence needed: a provider, a privacy review, and an unsubscribe path

SUG-14 · blocked-on-account · Impact 5/5 · Effort 4/5

Connect the Creators API or PA API and serve live price and availability

This is the only route that makes a price legal to display, and price is the single most-requested datum on a buying page. It also unlocks real availability, which prevents sending readers to an out-of-stock listing.

Evidence needed: Associates account approval plus API credentials

SUG-15 · shipped · Impact 2/5 · Effort 2/5

Add structured data for articles and breadcrumbs

Article and BreadcrumbList markup help a search engine describe the page correctly. Product and Offer markup is deliberately excluded, because marking up an offer implies price and availability data this site does not have.

Evidence needed: rich-result eligibility check after indexing

SUG-16 · blocked-on-account · Impact 4/5 · Effort 3/5

Add a visual product gallery with Amazon-hosted imagery

Images carry a buyer further than paragraphs. But Program Content may not be altered, and an image cannot be used in a way that implies an endorsement.

Evidence needed: a compliant image route: Amazon-served widgets, or the API's image fields used unmodified

SUG-17 · shipped · Impact 3/5 · Effort 1/5

Publish a per-guide 'what we could not verify' box

Stating the limits next to the recommendation is what separates a publication from an advertorial, and it costs one component.

Evidence needed: none

SUG-18 · rejected · Impact 1/5 · Effort 4/5

Run paid search to accelerate

It is the fastest way to buy traffic.

Evidence needed: n/a
