FLG-001 high

Every submitted path code is 9 characters; every ASIN observed on arrival is 10

Expected
An Amazon Standard Identification Number is a 10-character alphanumeric identifier.
Found
All five submitted codes (B04G1MEwY, B02NbDxp3, B00hJ57DV, B0c8moW59, B0f3GKalj) are 9 characters and contain lowercase letters. The four destinations that resolved carry 10-character uppercase ASINs: B0CDY277D3, B09B7SB46R, B08DKYBTPH, B0DZFD6R9Z.
How to read it
The submitted codes are most likely short-link slugs rather than identifiers. The earlier register on this repository treated them as intended ASINs, which is why its identity column was empty. That reading is corrected here.
What the site does about it
The 'intended_asin' field is null for all five rather than filled with the slug. Filling it with the slug would have been an inference.
Blocks
nothing — but it explains why the register looks emptier than expected

Where to check it yourself

  • https://affiliate-program.amazon.com/help/operating/agreement
  • Open each supplied link and compare the /dp/ segment to the code in the link
FLG-002 high

The buy links carried no Associates tag until this build

Expected
Program Policies 2(b): the Associates ID must appear as a parameter in the URL of each link placed on the site.
Found
After following the redirects on 2026-11-20, all five supplied links ended on a bare /dp/<ASIN> address with no tag parameter, and the site itself was offering those bare addresses as click targets. Whether the redirect service applies the tag server-side could not be observed.
How to read it
A /dp/ link without the tag is not a Special Link. Amazon's own application-review page lists untagged product links among the reasons an application is rejected, which makes this a revenue defect and an approval risk rather than a polish item. It is not a claim that the supplied short links are invalid: their exact behaviour remains unknown, which is FLG-003.
What the site does about it
The build now emits /dp/<ASIN>/?tag=shopnow047c-20 for every buy link, keeps the submitted code in the record, and fails the check if an untagged Amazon retail link appears. Attribution is still unconfirmed until a click shows in the report.
Blocks
earning anything, until one click is confirmed
