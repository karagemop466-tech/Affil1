FLG-001 high

Every submitted path code is 9 characters; every ASIN observed on arrival is 10

Expected
An Amazon Standard Identification Number is a 10-character alphanumeric identifier.
Found
All five submitted codes (B04G1MEwY, B02NbDxp3, B00hJ57DV, B0c8moW59, B0f3GKalj) are 9 characters and contain lowercase letters. All five destinations now resolve, and they carry 10-character uppercase ASINs: B0CDY277D3, B09B7SB46R, B08DKYBTPH, B0DHZTCNR5 and B0DZFD6R9Z.
How to read it
The submitted codes are short-link slugs rather than identifiers. The register records what arrived, and keeps the two fields separate.
What the site does about it
The intended_asin field is null for all five rather than filled with the slug. Filling it with the slug would have been an inference.
Blocks
nothing — but it explains why one column is empty

FLG-022 high

The only supported route to price and availability data is gated behind 10 qualifying sales

Expected
A site can decide to add prices once it has a data feed.
Found
Program Policies §2(b) still names “Creators API or PA API” as the permitted route. Amazon's own documentation now records PA-API 5 as deprecated and returning 403 AccessDeniedException, and lists the Creators API prerequisites as Associates enrolment, at least 10 qualifying sales within the past 30 days, registration through Associates Central, and generated credentials.
How to read it
This turns the site's biggest missing feature into a sequencing problem rather than an engineering one. Prices arrive after the site proves it can sell, not before. A separate clause in the same section adds that a comparison-format price display must also show the lowest used price, which is a second reason this site's comparison table keeps its price column empty.
What the site does about it
The comparison table keeps its blank price column by rule, and the site's own price_rule wording was updated to name the deprecation rather than pointing at an API that no longer answers.
Blocks
any live price, rating or availability display, until the sales threshold is met
