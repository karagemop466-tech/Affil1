FLG-029 highresolved in code

The 'Add to basket' links carry no tag and are not Special Links

Expected
Every link to an Amazon Site that is meant to earn commission uses the Associates ID as a URL parameter (Program Policies 2(b): 'you must include your Associates ID or "tag" ... as a parameter in the URL of each link you place on your Site to an Amazon Site'), and Amazon notes that purchases can be disqualified when 'the links from your site to the relevant Amazon Site are not properly formatted' (Commission Income Statement 2(g)).
Found
Both the front page and the products page publish five 'Add to basket' links at https://www.amazon.com/gp/aws/cart/add.html?ASIN.1=<ASIN>&Quantity.1=1 with no tag. They are marked rel="sponsored" and labelled 'paid link', so they read as earning links while being incapable of attributing a purchase.
How to read it
The cart permalink was added as a reference layer next to the listing link and is treated by the build as a permitted non-tag URL. It is not. Program Policies 2(b) applies to every link placed on the site to an Amazon Site, and the safe reading of a cart permalink is that it is a link to an Amazon Site. Either it carries the tag, or it is not presented as a buy action.
What the site does about it
A reader who uses them is taken to an Amazon cart that no Associated account is attached to. The site earns nothing, and the button is the most prominent call to action on the page.
Blocks
any claim that the primary call to action can earn, and any traffic spend
Resolution
Resolved in code on 2026-11-20 by session arena/acb1e4c8-affil1, during the merge that brought this flag onto the branch. _tools/cta.py no longer builds a cart permalink from an observed ASIN and no longer appends the tag by hand. pair() now renders the cart door only when paid_link_gate holds an account-approved Special Link for that ASIN; otherwise the primary door is the official listing for the observed ASIN via buy_url() -- the same gate every other Amazon link uses -- still marked rel="sponsored nofollow noopener", with a one-line note saying why there is no one-click basket. No published page contains a cart/add.html URL. Regression test: _tools/test_cta_gate.py (4 cases). The remaining question in this flag -- whether a tagged cart permalink is itself a permitted Special Link -- is not answered here and does not need to be until the account issues one; it is D-01 on /decisions/.
