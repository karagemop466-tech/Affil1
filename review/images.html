Image policy

Every photograph here
is an illustration

The brief asks for a polished, image-led storefront. There is a real tension in that: Amazon's Program Policies bar misleading claims about a Product, and an AI-generated 'photo' of a product placed next to a buy button reads to most shoppers as a photo of that product. This page states the rule the site follows so a reviewer can challenge it.

16 generated assets · 0 product photographs · 3 uses declined

The rule

One visual language: every image on this site is an engraved, two-colour editorial illustration. No photographic imagery, because a photograph beside a buy button reads as a photograph of that product, and none of these images is a photograph of a product. Never depicts a brand mark, never implies a price or a feature the listing does not state.

Three things this site declined to do

Use the listing's own product photography as the card image

Amazon's Program Content rules and the IP licence govern use of listing images and require them to come through permitted Program Content channels. Without PA API or Creators API access there is no permission basis for this build to copy them, so they are not used.

Source: SRC-02

Fetch each listing's live price on page load

Explicitly outside what the Program Policies permit without Amazon-served data or API access, and it would also be a third-party request from the reader's browser.

Source: SRC-02

Put a star rating next to each card

Same clause. Also unciteable: ratings change and this build cannot timestamp them from a permitted feed.

Source: SRC-02

Why this page exists at all

A shopper scanning a product page does not carefully separate the photograph from the product. If an image of a beautiful uncluttered kitchen sits above a buy button, most people will read it as a picture of the thing being sold. That is the risk, and it is why every use carries a visible label rather than a footnote.

The alternative — real photographs of the real products — requires owning them. That is item S-12 on the suggestion queue.
