Executive summary · 20 November 2026

Useful publication first. Automation behind a gate.

A summary of what this repository now supports, what its evidence does not yet support, and the shortest responsible path to launch.

Bottom line

The repository started with only a minimal README. It now contains a polished, responsive kitchen buying-journal site, four original question-led guides, a transparent five-link intent register, a suggestions and review area, a blank campaign ledger, SEO files, an analytics event schema and a self-hosted endpoint implementation. The five supplied links have not been verified; they remain quarantined from product-specific claims. Analytics is not live and GitHub Pages deployment is not confirmed until the hosting workflow runs successfully.

Confirmed from the project brief

  • Selected tracking ID supplied by the owner: shopnow047c-20. Enrollment and attribution are not confirmed.
  • Five exact URLs were supplied: https://link.amazon/B04G1MEwY, https://link.amazon/B02NbDxp3, https://link.amazon/B00hJ57DV, https://link.amazon/B0c8moW59, and https://link.amazon/B0f3GKalj.
  • The brief frames the subject as kitchen appliances and suggests air-fryer guide hypotheses. No exact product-to-link mapping or product identity was supplied.
  • Exact short-link Associates compliance status is unresolved; this work does not claim the links are invalid.

What is built

  • Publication home with buyer-oriented headlines, editorial visual, product shortlist, guides, and a compact navigation group.
  • Four original question-shaped articles focused on format, capacity, cleanup/space, and multi-function purchase questions.
  • Product intent register with intended ASIN/listing/date/source kept separate from observed redirect target. Unknown fields remain blank.
  • Dedicated suggestions page with explicit decision questions, evidence gaps, discovery steps, prioritization advice, and a locally saved choice.
  • Interactive comparison checklist, flagged-for-review page, sources/disclosure page, and empty provenance ledger.
  • Sitewide above-the-fold and footer Amazon disclosure; outbound product links are marked `rel="sponsored nofollow noopener"` and labeled as affiliate links.
  • Canonical metadata, robots file, sitemap, RSS feed, static GitHub Pages workflow, and five defined first-party analytics events with a self-hostable endpoint.
  • AI product discovery, trend/high-conversion scoring, automated content publishing, and campaign optimization are not implemented or live; no approved product feed, report data, or API credentials were supplied.

Critical gaps before product promotion

  1. Confirm the intended product, exact model, ASIN, official listing URL, and confirmation date/source for each link.
  2. In the enrolled Associates workflow, test each link; keep intended destination and observed redirect target distinct; verify tracking ID and reporting attribution before scaling.
  3. Confirm program enrollment/site approval and review each disclosure context against the current Amazon agreement and FTC endorsement guidance.
  4. Deploy and test the analytics endpoint on an approved first-party host; the GitHub Pages front end does not execute server code.
  5. Enable GitHub Pages via Actions and verify the actual deploy run and live URL; a workflow file alone is not a deployment.
  6. Verify Google Search Console ownership and submit the sitemap. No query data or organic-traffic result exists yet.

Recommended next steps

  1. Gate product facts and links. Complete the register, then release only claims that have official exact-model evidence.
  2. Publish the four guides. Keep them buyer-useful and generic until item identities and sources are verified.
  3. Start a modest editorial rhythm. Proposal: one thoroughly sourced guide every two weeks for the first eight weeks, then review workload and actual Search Console query/page data monthly. This is a suggested cadence, not a forecast.
  4. Measure only authorized data. Test page, guide, outbound click, comparison, and suggestion-selection events. Keep eligible sessions, clicks, and orders in the dated ledger only when sourced from authorized reports.
  5. Choose the next topic from evidence. Until Search Console data exists, treat all proposed headlines as hypotheses, not proven search demand.

Official references reviewed

  • Amazon Associates Operating Agreement — required site Associate statement and program terms.
  • Amazon Associates Program Policies — program content, price and availability handling.
  • FTC Endorsement Guides Q&A — disclosure of affiliate relationship near recommendations/links.
  • Google Search Console — ownership, sitemap, and query/page performance.
  • Google sitemap guidance — feed/sitemap submission behavior.
  • GitHub Pages custom workflows — static deployment requirements.
