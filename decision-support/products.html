Reading this shelf

Why there are no prices

Not caution — a rule. Amazon's Program Policies allow an Associate site to show price or availability only when Amazon serves the link containing that data, or when the publisher obtains it through Creators API / PA API and obeys the licence. We have no API access and no report access, so a price here would be an invented price. The same rule blocks star-rating and "best seller" badges on this page until the data source exists.

Source: Associates Program Policies, Participation Requirements §2(b), updated April 14, 2026. Cross-reference: the five rules.

Captured, not current. Every spec above is quoted from a snapshot of an official Amazon product page taken on 2026-11-20 through a search index, not from a live API call. One action per product

What closes each row

Four rows close with one browser session inside Associates Central. The fifth needs a decision from you.

P-01 · P-02 — the two clean rows

Run the enrolled-workflow test

Both registers already agree on the destination, so the only missing evidence is the affiliate mechanics: build a link for the candidate ASIN in Associates Central, click it once from a staging page, then check the reports show a click attributed to the expected tag. Record the destination, the date and who confirmed it. One product first, then scale — that is the sequence the brief asks for.

P-03 · P-05 — audit-observed rows

Confirm the audit, then finish the copy

These two rows were the register contradiction: one file said product page, the other said Amazon homepage. A same-day audit observed them reaching /dp/B08DKYBTPH and /dp/B0DZFD6R9Z, and both registers now say so. That is still another sandbox's fetch — and for P-05 a later report contradicts it outright (FLG-016, the thermometer swap). The enrolled workflow has to reproduce each destination from a click we make ourselves before reader-facing copy or tagged links go live. IRR-02.

P-04 — the swapped-pair row

Decide, then either fix or drop

This row started as the worst in the register: a bot checkpoint where a listing should be, two competing identifiers, nothing to publish. A late audit recorded the link reaching B0DHZTCNR5; a different session reports it reaching B0DZFD6R9Z instead, with P-05 swapped (FLG-016). Two third-party observations, directly contradictory — one is wrong and neither is ours. Reproduce it logged-out and in the workflow; if it holds, give the product a card, if not, pull it off the shelf. A thermometer whose evidence is somebody else's fetch should not sit in front of buyers with confident copy.
