FLG-003Unresolved

Compliance status of the supplied short links and the supplied tracking ID

The five link.amazon tokens are 9 characters each; an ASIN is 10 characters, so they are not ASINs. No documentation for the link.amazon format was found in the Amazon Associates Help pages reviewed. A control test showed this site's fetch path strips the tag parameter from resolved URLs, so neither the presence nor the absence of a tag on these links could be observed. The links are not asserted to be invalid.

What would settle it: In the enrolled Associates workflow, generate one Special Link per product with the account's own link builder, click it, and confirm the click appears in the account's own report before scaling.

Source: https://affiliate-program.amazon.com/help/operating/agreement

FLG-006Needs admin action

Two Pages build paths run on every push

The repository's Pages source is “Deploy from a branch” (legacy). Both the legacy branch build and the GitHub Actions workflow deploy successfully on every push to main. Switching the source to “GitHub Actions” would leave a single path, but the integration token cannot change it: PUT /repos/{owner}/{repo}/pages with build_type=workflow returns HTTP 403 Resource not accessible by integration.

What would settle it: A repository administrator can set Settings → Pages → Source to GitHub Actions in the web UI.

Source: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

FLG-009Needs review

A dated observed price is republished on the desk pages

The product records page shows three price observations recorded on 20 November 2026, each with the listing URL it was read from. The IP License says Product Advertising Content is obtained through Creators API or PA API, and that it may not be altered. A dated observation of a public price, shown with its source and its date and never shown on a reader-facing page, is a different act from displaying a live price, but the distinction has not been confirmed with the program.

What would settle it: Ask the program, or a reviewer, whether a dated observed price may appear on an editorial record page. If the answer is no, remove the price rows from the desk and keep only the fact that a price was observed on a given date.

Source: https://affiliate-program.amazon.com/help/operating/policies

FLG-008Needs legal review

The brief asks for an AI layer; the IP License restricts that use

The brief asks for an AI-powered platform that researches, scores and generates content. The Associates IP License states that Special Links and Program Content may not be used to develop machine learning models or related technology without express prior written approval, and that Product Advertising Content must be used only for the principal purpose of advertising and marketing an Amazon Site.

What would settle it: Obtain written guidance before building. Point any assistant at the site's own editorial records and at openly licensed material, and keep Amazon content out of training and out of automated feeds.

Source: https://affiliate-program.amazon.com/help/operating/policies
