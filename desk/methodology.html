The desk · Method

How we verify,
and why.

A short method, applied consistently, with the limit of each source stated next to it. If a value is not on this list, it is not published.

The rule

A value appears on this site only if it was read from an official source, with the URL and the date recorded. Where that is not possible, the cell is blank, the line is flagged, and the reason is on the flagged-for-review page.

How a product record is built

  1. Intent. Record the intended ASIN and the official listing URL separately, with the date confirmed and the source named.
  2. Observation. Follow the submitted link and record where it resolves, in its own field, with the date.
  3. Never merge. An observation never becomes an intent, and an intent is never treated as an observation.
  4. Specification. Repeat only what the official listing states. Everything else is blank.
  5. Price and rating. These are Product Advertising Content. The IP License permits them only through the Creators API or PA API, so the shop pages show none, and the desk records dated observations with their source.

What we do not publish

  • Star ratings or review counts that were not read from an official source.
  • Review summaries written by anyone other than a reviewer.
  • Search volume, popularity, best-seller ranks or trend claims.
  • Commission rates, click counts, order counts or revenue.
  • Any statement that we have used or handled a product.
  • Any superlative we cannot evidence.

Disclosure and links

The statement “As an Amazon Associate I earn from qualifying purchases.” appears above the masthead on every page of this site and is repeated in the footer. The FTC's Endorsement Guides say an affiliate relationship should be disclosed clearly and conspicuously, that “affiliate link” on its own is not adequate, and that the closer the disclosure is to the recommendation the better.

Every outbound product link carries rel="sponsored nofollow noopener". Product links are Special Links built from the tracking ID supplied by the site owner; whether that ID is enrolled on an account is FLG-003.

The rules we apply

  • Disclosure above the masthead, on every page.
  • Sponsored marking on every outbound product link.
  • Disclosure repeated in the footer of every page.
  • No price, rating or availability on reader-facing pages until the API is connected.
  • No claim that we have handled the products we write about.

Privacy and measurement

The tracker on this site is privacy preserving by design: no cookies, no advertising identifiers, no fingerprinting and no cross-site identifiers. It records five event types and nothing else. The server keeps a truncated, daily-rotated salted hash of the IP address rather than the address itself, and the referrer host rather than a full referrer URL, so a search query in a referrer is not stored.

Nothing is collected until the endpoint is deployed. The collector code is in the repository, and the ledger stays empty until an authorised first-party report is imported.

Retention and access

  • Events retained for 90 days, then discarded.
  • No personal identifiers, no account identifiers, no order data.
  • Outbound click events record the destination host only, never the query string.
  • The privacy notice must be written against the deployed behaviour before the collector is switched on. That is gate row G-10.
