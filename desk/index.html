Where the receipts live.

The shop is for readers. The desk is for you: every record, every source, every open item, and every suggestion with a decision slot left empty for review.

The one rule this desk follows

Nothing is filled in unless it was read from an official source, and the source is linked. Where a value could not be confirmed, the cell is blank and the item is flagged. That rule applies to product specifications, prices, ratings, availability, review counts, search demand, click counts, orders and revenue.

Work from earlier passes of this site

Several sessions built this site in parallel. Their work is kept in the repository under archive/, one folder per session, with its internal links repaired so it still renders. It is not published and not deployed — the live site is the one publication above, so that two front doors never compete for the same reader or the same search result.

The comparison table is the one idea carried forward from that work; it is now the range, side by side, with every cell linked to the listing it was read from.
