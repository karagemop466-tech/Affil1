The desk · Publishing gate

What has to be true
before we publish.

8 checks a script makes on every build, and 4 that need a person. The automated ones run in scripts/check_site.py and fail the deployment if they break.

IDCheckHow it is enforcedTypeStateAuthority
G-01Disclosure strip sits above the masthead on every page

The Operating Agreement asks for the Associates statement to be clearly and prominently stated; the FTC says the closer the disclosure is to the recommendation, the better.

 Automated — every HTML file must contain the disclosure text above the masthead element.MachinePass FTC — FTC's Endorsement Guides: What People Are Asking
G-02Every outbound product link carries rel="sponsored nofollow noopener"

Marking the link tells a reader and a crawler that the link is a paid placement.

 Automated — every external link on a product surface must contain the sponsored token.MachinePass FTC — FTC's Endorsement Guides: What People Are Asking
G-03No live price, rating, review count or availability on reader-facing pages

Product Advertising Content may only be obtained through Creators API or PA API. Until that connection exists, the site shows none of it.

 Automated — the checker rejects price and rating patterns outside the desk pages.MachinePass Amazon Associates Program Policies
G-04Every table row carries a link to an official source

A row without a source is an assertion, not a finding.

 Automated — every row in the desk tables must contain at least one absolute URL to an official domain.MachinePass Amazon Associates Program Policies
G-05Unconfirmed values are blank and flagged, never estimated

Inventing a plausible number is the failure mode this site is built to avoid.

 Automated — blank cells render as “Not confirmed” with a flag reference; no interpolation is performed.MachinePass Amazon Associates Program Policies
G-06Intent fields and observed fields are stored separately

Merging them would let an observation become a claim without evidence.

 Automated — the product record schema keeps intent_* and observed_* in disjoint columns.MachinePass Amazon Associates Program Operating Agreement
G-07Every page has a title, a description, a canonical and an RSS link

One canonical site with consistent metadata is what makes it indexable.

 Automated — the checker verifies the head tags on every page.MachinePass GitHub Pages — GitHub Actions as the Pages source
G-08The sitemap and the feed contain every published page and guide

A guide that is not in the feed or the sitemap is a guide nobody finds.

 Automated — the checker diffs the page list against sitemap.xml and feed.xml.MachinePass GitHub Pages — GitHub Actions as the Pages source
G-09The analytics collector is deployed, or it is not loaded at all

A tracker that posts to an endpoint that does not exist is worse than no tracker: it implies measurement that is not happening.

 Human — confirm the endpoint responds before enabling the tracker site-wide.HumanPending Amazon Associates Program Policies

The IP License forbids using Program Content in a way that implies a person's or company's endorsement. We have not handled these appliances, and the copy must not suggest that we have.

Destination and tracking report must be confirmed before scaling.

The human half

Four checks cannot be automated, because they are judgements about context and language:

  1. The collector is really deployed. Confirm the endpoint answers before enabling the tracker everywhere.
  2. The privacy notice matches reality. Write it against what the deployed collector does, not against what it was meant to do.
  3. The endorsement context is honest. Read each product card as a reader would. We have not handled these appliances and the copy must not imply that we have.
  4. One link per product has been tested in the enrolled Associates workflow, with the destination and the tracking report confirmed.

Why the automated half exists

A disclosure strip that is present on fourteen pages and missing from the fifteenth is a real failure mode, and it is invisible until someone notices. Scripting the boring checks makes the human checks the only ones that need attention.
