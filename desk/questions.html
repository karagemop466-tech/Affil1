How to close a question

  1. Find the authorised source — the enrolled Associates account, the Product Advertising API response, or the official listing page.
  2. Record the date you read it and the exact URL. A finding without a date goes stale silently.
  3. Write the value into the record it belongs to, and leave every other field alone.
  4. If the source does not answer it, say so in the record rather than closing the question.

What a good answer looks like

Traceable, dated, and specific enough that someone else repeating the same step gets the same result. “The price is about seventy dollars” fails all three tests. “Listed at $74.99 on the official product page on 20 November 2026, source linked” passes all three.
