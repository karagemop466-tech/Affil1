D-01

Put the Associates tag on the five buy links now, so the site starts earning immediately.

Blocked

What it changes

Every outbound product URL.

What the source says

Participation Requirements 2(a)–2(b): Special Links must use your Associates ID as a URL parameter, and must be the links your account issued.

Amazon Associates Program Policies ↗

Missing before a decision
An account-generated Special Link, per ASIN, from SiteStripe or the Associates dashboard.
Who closes it
Account owner (needs the Associates login).
Blocked by a rule?
Yes. The tag can only be attached to a link the account issued. Tagging a URL rebuilt from a redirect observation would be a link the site invented.
Recommendation
Not until the account confirms each ASIN.

Blocked

What it changes

What the source says

Participation Requirements 2(b): a site may show prices and availability only where Amazon serves the link carrying that data, or where it arrives via the Creators API or the PA API.

Amazon Associates Program Policies ↗

Missing before a decision
Either a Special Link that renders Amazon's own price widget, or Creators/PA API credentials and the qualifying-sales history those APIs require.
Who closes it
Account owner; the API path also needs the sales history.
Blocked by a rule?
Yes. A static page has no permitted source for the number.
Recommendation
Keep linking to the live listing. The price cells now do that explicitly.
