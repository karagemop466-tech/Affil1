Before you buy

Three things to measure

  1. The spot. Measure the width, height and depth where it will sit. Compare with the manual’s clearance requirements.
  2. The opening. Make sure you can pull the basket or swing the doors open without moving the appliance.
  3. The meal. Check the inside dimensions against what you cook, not just the number on the carton.

A format is a starting point, not a confirmed fit. This tool doesn’t have verified dimensions for these models.
