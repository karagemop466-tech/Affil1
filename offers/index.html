OFF-01Score 27

Confirm one Special Link in the Associates account and read the click report

The only task on this list that decides whether the site can earn at all.

What changes
One product's link becomes an account-issued Special Link with a confirmed click. The other four stay as they are until it works.
Why this rests on evidence
Program Policies 2(a): 'Special Links enable accurate tracking, reporting, and accrual of commission income.' Nothing in this repository can see the report.
What the owner does
Sign in, open Associates Central, generate one link, click it once, read the report.
If it goes wrong
Nothing on the site breaks; the register records 'tried, no click credited' and the site's position becomes known rather than assumed.
What it unlocks
Every revenue-dependent decision below.

OFF-02Score 22

Fix the deploy scope so the published site is only the published site

Stop serving the build scripts, the data registers and five retired storefronts.

What changes
Pages switches from 'deploy from the repository root' to the staged artefact, so /tools/, /src/, /archive/ and the retired editions stop resolving.
Why this rests on evidence
This session fetched the live https://karagemop466-tech.github.io/Affil1/tools/build.py and .../archive/notes-edition/index.html. Both returned 200 with content. github pages API reports build_type legacy, source.path '/'.
What the owner does
Settings → Pages → Source: GitHub Actions (one dropdown), or fix the path so the staged directory is what is served.
If it goes wrong
The site would go offline if the workflow is misconfigured; the previous commit stays deployable until it is right, and the owner should verify before closing the tab.
What it unlocks
Every 'one site to index' claim the brief makes.

OFF-03Score 21

Stop asserting a tagged relationship until it is confirmed

Either confirm the tag, or ship untagged reference links and say so.

What changes
The build stops adding ?tag= from a fallback. Buy links stay, but they become honest reference links until OFF-01 lands.
Why this rests on evidence
tools/paid_link_gate.py is the gate that is supposed to decide this. tools/validate.py does not import it. The generated pages publish the tag anyway. The disclosure strip says 'this site may earn a commission'.
What the owner does
Nothing — a session can do it. It is listed because it changes what the site claims.
If it goes wrong
Removing the tag reduces nothing if the tag was never credited, which is the current state, and is restored in one line once OFF-01 confirms.
What it unlocks
Nothing, but it is the safest default while OFF-01 is open.

OFF-05Score 17

Replace the photoreal holiday feature with a consistent illustration

The one section built to feel like a real publication has the one image that breaks the rule.

What changes
Either a licensed photograph with recorded provenance, or a re-drawn illustration in the same visual language as the other seven.
Why this rests on evidence
This session opened assets/img/holiday-hosting-counter-w900.jpg: it is a photorealistic kitchen photograph with warm light and a bokeh window. Every other image on the site is an engraving or wash drawing. src/data/images.json states the rule as illustrative-only; FLG-020 records that this asset has no origin.
What the owner does
Choose: licence a real photo, or commission the drawing. A session can draw; only the owner can licence.
If it goes wrong
Doing nothing keeps a small inconsistency, not a false product claim, because the caption does not say it is a photograph of P-02.
What it unlocks
Nothing.

OFF-07Score 15

Put a named human on the masthead

Or stop implying one is behind the notes.

What changes
A real byline with two true sentences, or an explicit 'anonymous desk' statement on every page.
Why this rests on evidence
FTC Endorsement Guides FAQ: an endorsement should reflect the honest opinion of the endorser. A site that reads like an experienced kitchen editor but names nobody is implying an endorser it does not have.
What the owner does
Supply a name and two true sentences, or approve the anonymous-desk wording.
If it goes wrong
An invented persona would be worse than the current state, so the fallback is the explicit statement, not a plausible name.
What it unlocks
Photography, first-hand testing, and any hands-on content.

OFF-09Score 10

Move off the repository subpath to an owned domain

A shop at a /Affil1/ path is a shop in a corridor.

What changes
Every canonical, the sitemap, the feed and the OG images point at one domain the owner controls.
Why this rests on evidence

Three directions

Pick a path, then pick rows

Individually sensible, collectively contradictory. The paths exist so the choice is one decision, not ten.

PATH-1

Make it earn

Prove one link pays before improving anything else.

Three of the ten offers touch whether money can arrive. The rest touch whether it arrives faster or from further away.

Offers: OFF-01, OFF-03, OFF-04
Cost: One owner session in Associates Central.

PATH-2

Make it honest

Remove the claims the repository cannot support, in the cheapest order.

Each of these deletes an assertion the site currently makes and cannot prove. None of them needs new content.

Offers: OFF-02, OFF-05, OFF-07
Cost: One Pages setting, one image, two sentences.

PATH-3

Make it found

Fix the address, verify the property, then write where the queries say.

Search traffic is the only channel that compounds, and it needs a stable address and a report to read.

Offers: OFF-09, OFF-06, OFF-08
Cost: A domain, a verification, and a publishing rhythm.

What this page cannot decide

Whether any of it earns. That is OFF-01, and it needs a login this repository does not have. Everything else on this page is sequenced around that single unknown.
