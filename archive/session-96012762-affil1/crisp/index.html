The one thing we will not do

What this site refuses to publish, and why it is a rule rather than a gap.

Amazon allows a site to show a price only when Amazon serves the link that carries it, or when the figure comes through the Creators API or PA API. This site has neither, so it shows no price, no star rating, no review count and no stock status. Not because the numbers are hard to find, but because publishing them without that feed is prohibited and, more plainly, because a price that was true last month is a lie this month.

The same discipline applies to the writing. Every capability sentence here is either quoted from the seller's listing title or left out. We have not tested these machines. We do not tell you which one cooks better, because we would be making that up.
