Quotations are reproduced as published. Where a page carries an update date, it is recorded, because a policy that changes silently is a policy you cannot rely on.

The compliance position, in eight lines

  1. The required sentence is on every page, above the first link. The Agreement’s wording is reproduced exactly, and the checker fails the build if it moves below an outbound link.
  2. Every outbound Amazon link carries the tag as a URL parameter. Direct /dp/ addresses with ?tag=shopnow047c-20, which is what section 2(b) asks for in plain words.
  3. Every outbound Amazon link is marked sponsored. rel="sponsored nofollow noopener", per Google’s guidance on paid placements.
  4. No price, stock, star rating or review count is published. No compliant data feed is connected, so the fields stay empty rather than going stale.
  5. No Amazon imagery is used. The photographs are original editorial illustrations and each one says so.
  6. No performance claim is made as our own. Listing language is reproduced and labelled; everything else is framed as a question or omitted.
  7. No deal badges, countdowns or limited-time promotion references. Section 2(b) makes each one a removal obligation the moment it expires.
  8. No third-party script, cookie or tracking pixel. The event script transmits nothing unless an endpoint you control is configured, and no endpoint is configured.
