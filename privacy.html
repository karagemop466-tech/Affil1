Privacy notice

Analytics

Affil1 uses a self-hosted, privacy-preserving analytics endpoint (/analytics/collect; collector code at server/collect.js). It records only five defined events:

EventWhat is recorded
page_viewPage URL, page title, referrer, session id, timestamp
outbound_clickOutbound link URL, link text, whether it is marked sponsored/product, session id, timestamp
guide_readGuide slug, session id, timestamp
suggestion_reviewSuggestion id, session id, timestamp
session_startSession id, timestamp
  • No cookies. A random session id lives in sessionStorage only (not sent to any third party).
  • No IP addresses are logged by the client code.
  • No personal identifiers are collected.
  • Events are queued locally and sent as newline-delimited JSON to the self-hosted collector, which appends them to an append-only log. If the collector is unreachable, the page still works and events remain in the browser only.

Affiliate links

Clicking a sponsored product link sends you to Amazon.com. Amazon’s own privacy and cookies policies apply there; Affil1 does not add tracking parameters beyond the Associates tag required by the program.

Data retention

The events log is append-only and rotated regularly; nothing is edited or deleted after collection. You can clear your browser’s localStorage to remove any locally queued events.
