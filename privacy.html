Privacy

What this site knows
about you, which is almost nothing

No cookies, no advertising identifiers, no third-party scripts and no analytics running. This page describes exactly what would be collected if measurement were switched on, because a notice added after the fact is not a notice.

Current state: analytics switched off · 0 cookies · 0 third-party requests

Today

Right now this site collects nothing. There is no analytics endpoint configured, no form, no account, no newsletter and no comment system. The pages are static files served by GitHub Pages, which keeps its own server logs under its own policy; that is outside this site's control and is not something this site can read.

Loading any page here makes exactly two kinds of request: for the HTML file itself, and for files in this repository (styles, fonts, images, one script). No request goes to a third party.

If measurement is switched on

The repository contains a measurement client and a self-hosted collector. Both are written and tested; neither is deployed. If the site's owner deploys the collector and sets one line of configuration, the following would be recorded:

EventRecorded whenWhat is stored
page_viewA page was rendered.The page path, with the query string removed. The date.
outbound_product_clickA reader activated a link to an Amazon listing.The page path, the product ASIN, the date. Not the destination, not the outcome.
guide_read_75A reader scrolled to 75% of a guide&#x27;s height.The page path, the date.
compare_viewThe comparison page was rendered.The page path, the date.
flag_page_viewThe review queue was opened.The page path, the date.

That is the whole payload: four fields per event, an aggregate count per day. There is no visitor record to retain, so there is no retention period to expire, and nothing that could be joined to a person.

What would never be collected

Never collectedWhy
IP addressNot read by the collector and not written anywhere. No forwarding header is trusted or stored.
CookiesNone are set. The client never touches document.cookie.
Local or session storageNot used. There is no persistent identifier, so two visits cannot be linked.
Query stringsStripped before anything is sent, so a search term in a URL is never transmitted.
Referrer URLNot collected. The site does not attempt to reconstruct search queries; Search Console does that properly.
User agent, screen size, device modelNot collected.
Anything after a clickAmazon's site is not observable from here. This site never claims to know whether a purchase happened.

Opting out

If Global Privacy Control or Do Not Track is set in your browser, the client sends nothing at all, including page views. There is no consent banner because there is no profiling, no advertising network and no cross-site tracking to consent to; a banner in front of an integer count would be theatre.

Amazon links

Clicking a product link takes you to Amazon, which has its own privacy policy and its own cookies. This site is not told what you do there, and makes no claim about it. Links carry the site's Associates tag so that a qualifying purchase can be attributed; the tag identifies the site, not you.

Changes

If the collector is deployed, this page changes in the same commit, and the change is dated in the publishing calendar. A privacy notice that changes silently is not worth reading, so this one is generated from the collector's own field list and the build fails if the two disagree.

The one thing to take from this page

The reason the site can say this plainly is that it does not run a third-party analytics product. That is a design choice with a cost: no traffic data means no data-driven decision, which is why measurement is the first item in the decision queue.
