Q-01Open Blocks work

Does each submitted link actually land on the product the owner meant to send readers to?

What we have
All five submitted links resolved to a live Amazon listing when re-checked on 2026-11-20, and the arrival ASIN and title were transcribed for each (P-01..P-05).
What is missing
The owner's intended ASIN for each. Every submitted path code is nine characters; every ASIN observed on arrival is ten. That is evidence the codes are short-link slugs rather than identifiers, so intent cannot be read off the link.

What would close it

In the Associates dashboard, open SiteStripe for each product and copy the tagged link for the exact ASIN intended, then record both values side by side.

Q-10Open Blocks work

Is the analytics endpoint live, and is it lawful to switch on?

What we have
The five event names and a client that stays silent by default.
What is missing
An endpoint, a privacy notice, a retention period, and a decision on consent for visitors in jurisdictions that require it.

What would close it

Publish the privacy notice first, then deploy the collector, then enable the beacon. The order matters.

Q-14Open Blocks work

Are the supplied links Special Links in the sense the agreement means?

What we have
Four resolve to live Amazon listings. None showed a tag on arrival.
What is missing
Confirmation that each is tagged with shopnow047c-20. The agreement requires Special Links to use the assigned Associates ID (SRC-02).

What would close it

Re-issue each destination as a tagged link from SiteStripe and replace the outbound URL after recording both the old and new value.

Q-02Open

Why does one link never resolve?

What we have
https://link.amazon/B0c8moW59 was requested three times and returned Amazon's /checkpoint/continue interstitial each time. No product page was reached.
What is missing
Whether the short link is expired, mistyped, region-restricted, or simply challenging this particular client.

What would close it

Open it once from a normal browser on the owner's own network and note the final URL. If it is dead, re-issue the link from the Associates dashboard.

Q-06Open

P-05 is a thermometer, not an air fryer. Does it belong in the same catalogue?

What we have
The listing title and its category path both put P-05 under Thermometers, not Air Fryers. The other four are all under Air Fryers.
What is missing
The owner's editorial intent — was the thermometer meant as an accessory to the air-fryer content, or as a separate line?

What would close it

One sentence from the owner. Until then the site treats it honestly: it is listed in its own section and never described as an air fryer.

Q-07Open

Which topics are worth writing about?

What we have
Four editorial hypotheses, clearly labelled as hypotheses.
What is missing
Any search data at all. No Search Console property, no impressions, no query list, no click data.

What would close it

Verify the property in Search Console, submit the sitemap, wait for impressions, then export the query report and pick topics from it. Until then the topic list is a guess and is labelled as one.

Q-08Open

Who is the author, and why should a reader trust them?

What we have
Nothing. There is no named person, no credentials, no first-hand testing.
What is missing
A real byline and a real basis for it. This is the single largest trust gap on the site and cannot be automated away.

What would close it

A named editor with a short, accurate bio. Claiming testing that did not happen would breach both the FTC guides and the Operating Agreement, so the bio must describe what the writer actually did.

Q-09Open

What is the actual commission rate for these categories?

What we have
Nothing. The rate card sits behind an Associates sign-in.
What is missing
The owner's own rate card.

What would close it

Read it in the Associates dashboard and record it. It is deliberately blank here rather than copied from a blog.

Q-11Open

Can this site be indexed at all, given the repository path?

What we have
The site is served from a project path on github.io. All internal links resolve within that path and the sitemap lists the same host.
What is missing
Verification that the sitemap has been submitted and that pages are actually being crawled.

What would close it

Search Console verification, then sitemap submission, then check coverage after a few days.

Q-15Open

Q-16Open

Which topics should the site write about next, and what is the evidence for them?

What we have
Six guides exist, all written from editorial judgement. None was chosen from a search query report, because no query report exists yet.
What is missing
A Search Console performance report or a Bing Webmaster report for the site, covering impressions, clicks and the queries that produced them.

What would close it

Verify the property in Search Console and submit the sitemap (S-07). Submit the same sitemap to Bing Webmaster Tools (S-13). Re-read the query report after four weeks and pick the next topic from the queries that already produce impressions but few clicks.

Q-04Answered

Should the site show prices?

What we have
Amazon's Program Policies allow showing price and availability only where Amazon serves the link carrying that data, or where it arrives via Creators API or PA API (SRC-02).
What is missing
A decision, and if the answer is yes, API credentials.

Answer

No price, star rating, review count or stock status appears anywhere on this site, because neither permitted data path is connected.

Q-05Answered

Is the disclosure in the right place?

What we have
The Operating Agreement requires the exact statement on the site (SRC-01). The FTC says a footer-only disclosure is easy to miss and that proximity to the recommendation matters (SRC-03).
What is missing
Nothing structural. What remains is a legal review of the wording around it, which this build cannot perform.

Answer

The required sentence sits in a strip above the masthead on every page, and repeats in the footer. Each product card carries its own one-line affiliate note so a reader who never scrolls still sees it.

Q-12Answered

Does the site make any claim it cannot support?

What we have
Every page was machine-checked for banned patterns: no price figure, no star rating, no review count, no stock status, no superlative, no test claim.
What is missing
A human read for tone and implication — a checker cannot catch a sentence that is technically true but suggests more.

Answer

No page claims testing, ranking or a winner. Every product page says plainly that the product was not tested.

Q-13Answered

What happens if the owner never supplies the missing account data?

What we have
A site that is compliant but thin: five product records, four of them identified, honest guides, no prices.
What is missing
A decision about how long to wait.

Answer

Nothing on the site breaks. It stays accurate because it claims so little. The cost of the missing data is opportunity, not correctness.
