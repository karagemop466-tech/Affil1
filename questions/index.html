Blocking questions

Until one of these is answered, work that depends on it is either guesswork or wasted.

Q-01Open Blocks work

Does each submitted link actually land on the product the owner meant to send readers to?

What we have
All five destinations reached Amazon listings on the latest pass; the observed ASIN is not a confirmed intended ASIN.
What is missing
The owner's intended ASIN. Every submitted path code is 9 characters; every ASIN observed on arrival is 10. That is evidence the codes are short-link slugs, not identifiers, so the intended product cannot be read off the link itself.

What would close it

In the Associates dashboard, open SiteStripe for each product and copy the tagged link for the exact ASIN intended, then record both values side by side.

Q-02Open Blocks work

Will P-04 reliably reach the intended product?

What we have
Earlier requests showed a checkpoint. The latest direct request reached ThermoMaven B0DHZTCNR5.
What is missing
Stable destination, intended ASIN and tracking evidence.

What would close it

Match the intended variant in SiteStripe and validate the exact destination against an authorized tracking report.

Q-03Open Blocks work

Are the clicks actually attributed to shopnow047c-20?

What we have
The tracking ID was supplied in the brief. Nothing on any arrived-at page showed a tag parameter.
What is missing
Evidence that the link the server serves carries the tag, and a click that then shows up in the Associates click report.

What would close it

One test click on the owner's own device, then check the Associates click report for that day. That is the only permitted source for this number.

Q-10Open Blocks work

Is the analytics endpoint live, and is it lawful to switch on?

What we have
The five event names and a client that stays silent by default.
What is missing
An endpoint, a privacy notice, a retention period, and a decision on consent for visitors in jurisdictions that require it.

What would close it

Publish the privacy notice first, then deploy the collector, then enable the beacon. The order matters.

Q-14Open Blocks work

Are the supplied links Special Links in the sense the agreement means?

What we have
Five reached listings in this check. No arrival URL displayed the supplied tag; that alone cannot establish attribution.
What is missing
Confirmation that each is tagged with shopnow047c-20. The agreement requires Special Links to use the assigned Associates ID (SRC-02).

What would close it

Re-issue each destination as a tagged link from SiteStripe and replace the outbound URL after recording both the old and new value.

Q-06Open

Do the two thermometer observations belong in the comparison?

What we have
P-04 and P-05 reached meat-thermometer listings; the other three reached air fryer listings.

The owner's editorial intent — was the thermometer meant as an accessory to the air-fryer content, or as a separate line?

Keep the thermometer decision separate from the air-fryer capacity table, and verify why each product was submitted before adding a paid CTA.

Q-07Open

Which topics are worth writing about?

What we have
Four editorial hypotheses, clearly labelled as hypotheses.
What is missing
Any search data at all. No Search Console property, no impressions, no query list, no click data.

What would close it

Verify the property in Search Console, submit the sitemap, wait for impressions, then export the query report and pick topics from it. Until then the topic list is a guess and is labelled as one.

Q-08Open

Who is the author, and why should a reader trust them?

What we have
Nothing. There is no named person, no credentials, no first-hand testing.
What is missing
A real byline and a real basis for it. This is the single largest trust gap on the site and cannot be automated away.

What would close it

A named editor with a short, accurate bio. Claiming testing that did not happen would breach both the FTC guides and the Operating Agreement, so the bio must describe what the writer actually did.

Q-04Answered

Should the site show prices?

What we have
Amazon's Program Policies allow showing price and availability only where Amazon serves the link carrying that data, or where it arrives via Creators API or PA API (SRC-02).
What is missing
A decision, and if the answer is yes, API credentials.

Answer

No price, star rating, review count or stock status appears anywhere on this site, because neither permitted data path is connected.

Q-05Answered

Is the disclosure in the right place?

What we have
The Operating Agreement requires the exact statement on the site (SRC-01). The FTC says a footer-only disclosure is easy to miss and that proximity to the recommendation matters (SRC-03).
What is missing
Nothing structural. What remains is a legal review of the wording around it, which this build cannot perform.

Answer

The statement sits after the masthead and before the content. It repeats in the footer. An approved paid CTA is labelled beside the link.

Q-12Answered

Does the site make any claim it cannot support?

What we have
Every page was machine-checked for banned patterns: no price figure, no star rating, no review count, no stock status, no superlative, no test claim.
What is missing
A human read for tone and implication — a checker cannot catch a sentence that is technically true but suggests more.

Answer

No page claims testing, ranking or a winner. Every product page says plainly that the product was not tested.

Q-13Answered

What happens if the owner never supplies the missing account data?

What we have
Five product records with observed destinations, guides and no prices; intended identities and attribution remain unconfirmed.
What is missing
A decision about how long to wait.

Answer

Nothing on the site breaks. It stays accurate because it claims so little. The cost of the missing data is opportunity, not correctness.
