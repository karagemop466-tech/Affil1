The whole project

Three steps

Do them in this order. The order is the finding.

01

Sign in to Associates Central once

about ten minutes

This is the only step that decides whether the site can earn. Everything else on this page is an improvement to a shop that may not be able to be paid.

What you do
Generate one Special Link for any one of the five products, click it yourself, then open the click report and see whether the click appears against shopnow047c-20.
What happens then
Paste that one link back into this project and shape the other four. Until then the site keeps working, keeps disclosing, and keeps making no claim about earnings.
02

Change one Pages setting

two minutes

The live site is currently serving its own source code and five retired storefronts. Search engines are being invited into all of it by robots.txt.

What you do
Repository Settings → Pages → set the source to GitHub Actions so the staged build is what gets published, not the repository root.
What happens then
Everything under /tools/, /src/, /archive/ and /decision-support/ stops resolving, and the site a crawler sees is the site the build makes.
03

Add the tag back only after step 1 proves a click

nothing yet

The site now publishes no tag at all: every Amazon destination is the plain listing. That is the honest state while no Special Link is approved, and the checker fails the build if a tag reappears without evidence.

What you do
Nothing today. After step 1 confirms a click, record that one approved Special Link and the tag returns for that product only.
What happens then
The disclosure strip does not change, because it states an obligation rather than a result.
