How to use this board

Work down the list and mark each row. The buttons record your decision in this browser's own storage so you can come back to it. Nothing is transmitted, there is no account, and nobody is notified — the site has no backend by design.

When you are ready, use Copy decisions to get a plain-text summary to paste into an instruction. That is the hand-off: a person chooses, then the next build acts.
