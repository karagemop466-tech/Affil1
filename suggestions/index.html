Choose a path before choosing a row

The rows are not independent. Approving the eighth one while the first is open produces a bigger site with the same problem. So pick a strategy from the three below, then work through its rows. The preconditions for every row are written out on Before you decide.

Marking a row writes to this browser's own storage. There is no account, no backend and nothing is transmitted. Copy decisions turns the marks into plain text you can paste into a message: that is the hand-off, a human deciding and then instructing.

The recommendation, stated plainly

Path A first, and only Path A. Two of its four rows are already done in the build and the remaining two cost one click and one template change. Until a click appears in the Associates report, a fifth guide is a guess about demand and a tested product is a guess about interest.

Then Path B, because publishing without measurement is how a site arrives at forty pages and no readers. Path C is the only one that produces something a competitor cannot copy, and it should start the week you decide you are still doing this in a year.
