What changed,
and what we refused to change

Seven decisions shipped in this release, three suggestions declined with reasons, and four questions that need a person rather than an agent. Each row carries the source it rests on or the gate that enforces it.

Most change logs describe what was built. This one is written for the person who has to decide what happens next, so the two columns that matter are evidence and cost, and the most useful section is the declined list.

A suggestion that cannot name its source is a preference. Every row below either links an official document or a page on this site that shows its working.

Declined

Three suggestions we are advising against

Each of these is the obvious next move, and each one would cost more than it returns right now.

Suggestions the owner should reject, for now
RefSuggestionWhy not yetWhat enforces itSource
N-01Do not add prices, ratings or review counts yetProgram Policies section 2(b) permits price and availability only where Amazon serves the data or it arrives through the Creators API or PA API. Neither is connected, and the API that would supply it is gated behind qualifying sales.The site&#x27;s build fails on a currency figure rather than trusting an editor to remember.Amazon Associates Program Policies
N-02Do not call the supplied short links invalidEvery submitted code is nine characters where an ASIN is ten, which makes it a short-link slug rather than an identifier. That is a fact about the string, not a ruling on its compliance, and no enrolled-workflow test has been run.The distinction is published as FLG-003 rather than resolved by assertion.Amazon SP-API: Catalog Items (ASIN format)
N-03Do not publish a ranking, a winner or a test resultNothing on this site has been bought, cooked with or measured. The FTC&#x27;s guidance on endorsements treats an implied test as a claim, and inventing one to move a commission is the specific failure mode an affiliate publication is prone to.The build refuses first-person testing language, star ratings and ranking words anywhere in visible text.FTC endorsement guides: what people are asking

A declined row is not permanent. Each names the condition that would change the answer.
