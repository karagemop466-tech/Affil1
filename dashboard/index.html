Irregularities found while re-verifying

Every submitted path code is 9 characters long. Amazon's own Catalog Items reference treats an ASIN as the item identifier, and every destination ASIN observed on these pages is 10 characters; none of the five supplied codes can be matched to a catalog ASIN as written. The slug is therefore recorded as a short-link path code, never as an intended ASIN.

None of the five submitted URLs carries a tag parameter, and each works by redirect through an intermediate host. Under the Associates Commission Income Statement, purchases arriving through a Redirecting Link, or through a link that is not properly formatted, are disqualified — so as submitted these links cannot be attributed to the tracking ID. Replacing them with Special Links generated in Associates Central is the single highest-value change available to this project.

Corrections applied this pass: an archived register recorded rows P-03 and P-05 as reaching only the Amazon homepage; both reach product pages, and P-05 is a meat thermometer rather than a fryer. The archived file is preserved unchanged at archive/2026-11-20-integration/data/confirmations.json so the disagreement stays reviewable.
